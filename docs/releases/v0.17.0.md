# v0.17.0 — Full album loading

- Add **Load all album tracks** / **Stop loading** for albums with remaining pages, bounded to 50,000 raw entries and one request at a time.
- Preserve raw offsets and totals through browsing, Back/Forward snapshots and playback continuation. Unavailable entries advance pagination; repeated songs remain separate occurrences.
- Validate account, generation, album identity, count and page progress before merging. Stop follow-ups on navigation, refresh, local mutations, account changes, errors or close; yield while playback buffers.
- Loading never starts playback or changes the queue. A stopped in-flight page may finish. Album reads are not atomic revision snapshots; Refresh checks external catalog changes.

Verified with 218 normal tests, strict Clippy/format checks, release compilation, isolated single-instance and Secret Service contracts, and native responsive fixtures/smoke. No live account mutations or audible/device tests.
