# Tidal Forces v0.15.0

## Load your saved library

- Library Tracks, Albums and Artists offer **Load all saved …** and **Stop loading**.
- Reads proceed one page at a time, up to 50,000 entries, without changing playback, the queue or favorites. Loading yields while playback buffers.
- Stopping keeps loaded items; an in-flight page may finish. Navigation, refresh, account changes, local writes, read errors and closing the window stop follow-up requests.
- Additional-page duplicates are skipped. Repeated pages, changing counts and invalid progress stop safely before unsafe data is merged.
- Unknown totals and unavailable items remain positive-only observations: a bulk read never turns unchecked favorites into “not saved.” These are best-effort reads, not an atomic snapshot; Refresh checks changes made elsewhere.

## Cohesive library controls

The control section now follows the roadmap: teal category tabs with a divider, a compact loaded-count/play/load row, an expanding search filter, quieter sort/reverse controls and a tinted selection strip with Copy links, Selection actions and Clear.

Selection-strip geometry stays stable so selecting rows does not move subsequent Ctrl/Shift-click targets or lose keyboard focus. Filtered library playback uses **Play shown** and the existing view-only playback contract.

## Verification

210 normal tests, strict formatting/Clippy, isolated single-instance and Secret Service contracts, release-mode checks and native layout/smoke checks. Coverage includes all three library categories, raw pagination, incomplete reads, overlap, bounds, cancellation, worker backpressure, occurrence selection and minimum/normal/high-zoom control layouts.

User-reviewed functionality and requested visual feedback are included. No agent-driven live account mutations, credential migration or audible tests were performed. Album catalog full loading and persistent caches remain separate future work.
