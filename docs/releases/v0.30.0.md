# v0.30.0 — Explicit-retry output recovery

Approved after native preview review.

- Audio initialization is lazy and recoverable. A missing output no longer kills
  the audio controller or permanently disables Play until the app restarts.
- Opening an output uses only the current system default, without Rodio's search
  through other devices if that output fails.
- Stream errors stop further complete-frame consumption, cancel preparation, and
  pause at the recorded software-rendered position without advancing the queue.
- Recovery requires explicit Play after choosing the desired system output.
  Fault epochs reject stale retries; a queued load or automatic next-track
  generation cannot acknowledge an output failure. No automatic restart.
- Native stream errors are signalled atomically rather than formatting/logging
  backend error details in the callback. Decoder/network/disk work stays off it.

## Limits

This is not yet an in-app device picker or a physical headphone-loss guarantee.
An OS-managed virtual default can be rerouted without a stream error; system route
monitoring, persistent device selection and real hotplug validation remain separate
P4 work. Source quality does not certify DAC output. AAC gapless, DSP/normalization,
unavailable-track skipping and radio remain unchanged.

## Verification

366 normal tests pass, with six opt-in tests excluded from the normal suite.
Formatting, strict Clippy on Rust 1.95/1.99, release checking, development build,
private native error-state fixtures/smoke, the two isolated D-Bus contracts and
the separately isolated null-output contract pass.

Synthetic tests cover frame-aligned failure gating, healthy samples, fault epochs,
stale events, occurrence/position preservation, prepared-next races and explicit
retry. The separately isolated null-ALSA contract checks failed initialization,
late output availability, recovery in the same controller, injected stream loss,
and stale retry rejection. See `docs/output-validation.md`. No real-device,
audible-playback or account-mutation tests are authorized by this slice.
