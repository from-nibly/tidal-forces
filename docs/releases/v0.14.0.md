# Tidal Forces v0.14.0

## Return to your loaded views

- **Back / Forward** restores recent loaded search, library and catalog views, including filter/sort settings, occurrence-aware selection and scroll position.
- Restoring a view does not restart playback or change the queue. The toolbar identifies a **Restored view**; **Refresh** fetches the latest data.
- Snapshots stay in memory for the current account, bounded to eight views and 50,000 table rows. They are not a persistent or offline library.
- Fresh page/link navigation still fetches data. In-flight, failed, oversized and evicted views reload normally; Home, Settings and folder views retain their existing behavior.

## Guarded restoration

- Account changes clear snapshots and old-account navigation. Local favorite and playlist writes invalidate snapshots before sending and on completion.
- Playlist raw positions, revisions and pagination offsets are preserved. Playback still authorizes media anew; cached metadata never replaces server write or subscription checks.
- Selection is rebound only to the same account's intact loaded snapshot, without stealing keyboard focus.
- Restoring browse data does not overwrite newer favorite membership. Appending to an old cached library prefix cannot incorrectly establish that unseen items are unsaved.

## Verification

197 normal tests, strict Clippy and formatting, isolated single-instance and Secret Service contracts, release-mode checks, native smoke/layout checks and user review. Tests include native scroll restoration, duplicate occurrence identity, no autoplay, stale responses, account isolation, memory bounds and mutation invalidation.

No live account mutations, credential migration/cleanup or agent-driven audible/device tests were performed. Persistent caches and remaining P3 organization tools remain future work.
