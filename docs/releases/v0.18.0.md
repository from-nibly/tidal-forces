# v0.18.0 — Playlist name and description editing

- Owned playlists with a known description offer **Edit details…**. Opening the editor is read-only; **Save changes** confirms a TIDAL account mutation.
- Names support 1–100 characters and descriptions up to 1,000, including clearing a description. The centered editor uses bounded scrolling at small sizes and high zoom.
- Freeze account, playlist and revision; recheck ownership/revision before the conditional write. Require a new write revision and exact metadata read-back before reporting success.
- Invalidate cached views before dispatch and on completion. Ignore foreign-account replies and prevent double dispatch. Uncertain writes require Refresh and inspection, never blind retry or rollback.

Verified with 225 normal tests, strict Clippy/format checks, release compilation, isolated single-instance/Secret Service contracts and native responsive fixtures. Live account mutation interoperability remains untested; no credential migration or audible/device tests were performed. Cover uploads, visibility changes and track reordering remain separate work.
