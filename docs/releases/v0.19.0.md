# v0.19.0 — Local playlist pins

- Add **Pin locally / Unpin locally** to loaded playlists. Account-scoped shortcuts appear in the sidebar and Library → Playlists & folders, including compact windows.
- Visible pin menus move shortcuts up/down or remove them without changing TIDAL favorites, folder order, queue or playback. Opening a pin uses normal authorized browsing.
- Save up to 64 playlist IDs and labels per account in private atomic files. Reads are bounded and versioned; malformed, oversized or wrong-account data cannot silently become empty writable state. Uncertain saves require reload.
- Signing out clears the in-memory view without deleting that account's pins.

Verified with 231 normal tests, strict Clippy/format checks, release compilation, isolated single-instance/Secret Service contracts, real synthetic menu clicks and native responsive fixtures/smoke. No live account mutations, credential migration or audible/device tests.
