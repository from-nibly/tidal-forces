# Tidal Forces v0.12.0

## Complete playlist loading

- **Load all playlist songs** fetches remaining pages of an open playlist, including read-only playlists, so filtering, sorting and selection can cover the complete loaded collection.
- **Stop loading** prevents further requests while keeping already loaded songs. An in-flight page may still finish. Loading never starts playback or changes the active queue.
- Reads stay pinned to the account, playlist revision and raw entry count. Changed or invalid pages stop safely without automatic retries. Navigation, refresh, cancellation and request failures also stop loading.
- Bounded to 50,000 playlist entries. New pages append without cloning or re-normalizing all previous tracks.
- Album/favorite full loading and persistent browse caches remain future work.

## Playback errors

- TIDAL error 4005 now explains that the song is not ready for playback instead of claiming the session expired. The app does not renew credentials or retry that unavailable asset in response to this code.
- Other authorization errors identify the failing stage and safe error codes without exposing tokens, URLs or private server messages. No authentication clients, permissions or DRM controls were changed.

## Verification

176 normal tests, strict Clippy and formatting, isolated single-instance and Secret Service contracts, release-mode checking, native smoke/layout checks and user native review. The user confirmed another song played after a track returned 4005. No live account mutation, credential migration/cleanup or agent-driven audible/device tests were performed.
