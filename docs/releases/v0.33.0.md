# v0.33.0 — P6 appearance and optional classic skins

Native review complete; operator approved publication and installation.

## Features

- Semantic colors across the native main, mini, lyrics, menu and error surfaces.
- Dark (default), Light, native System preference and contrast-checked Custom palettes.
  Local RGB JSON editing/export is bounded to 4 KiB; invalid cosmetics fall back
  without resetting unrelated playback preferences. No playback restart on changes.
- English-only embedded translation catalog foundation (operator choice), exact
  fallback and bounded schema/placeholder validation. No other language is advertised;
  dynamic diagnostics/remaining integration labels need coverage before one ships.

- Optional local classic `.wsz` main-panel skins in the existing mini player.
  Bounded ZIP/BMP decoding runs off the UI/audio threads; no extraction, plugins,
  scripts, downloaded art or modern `.wal` support. Native text, quality/status and
  shared actions remain authoritative; failures retain the existing appearance.
  Generation-scoped seek drags, keyboard controls and branded fallback are covered
  by tests. Private import/reload persistence has its own isolated-profile contract.

## Local verification

- 444 normal tests pass (10 opt-in tests excluded), on Rust 1.95 and 1.99.1;
  application strict Clippy and formatting pass. Existing vendored libpulse warnings
  remain on the newer compiler; this is not a dependency-security audit clearance.
- Scoped isolated IPC, Secret Service, null-ALSA, Pulse, PipeWire sample-delivery,
  tray and private skin-import contracts pass. No real account/device tests run.
- Optimized eager-link/version/license smoke and real private native mini lifecycle
  pass for Dark, Light and classic mode. 42 synthetic native layout captures cover
  themes and classic views at minimum/normal/zoom sizes.
- Short private idle samples use 0–0.02 CPU seconds per 3-second interval; RSS is
  approximately 123–133 MiB versus a 124 MiB v0.32 local baseline. This measures
  idle synthetic UI, not physical-device playback performance.
- New dependency notices are embedded. No third-party skin artwork is bundled.

## Scope and remaining gates

MilkDrop and additional platform ports remain later optional work. This release
does not add non-English translations, Google Cast or TIDAL Connect.

The approved native review preview is preserved during managed installation.
Version approval does not authorize account mutations, credential migrations or
real device/audio tests.
