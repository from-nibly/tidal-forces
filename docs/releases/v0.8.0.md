# Tidal Forces v0.8.0

Native library, queue and privacy foundations, with a reviewed dark/teal egui interface.
This release incorporates the v0.5–v0.8 development previews since v0.4.0.

## Highlights

- Library tabs, explicit favorite actions, persistent search, back/forward navigation,
  grouped Settings, compact rows and 75–150% UI scaling.
- Artwork-led pages, aligned virtualized track tables, folder/playlist sidebar rows,
  compact roadmap-style search, responsive Queue/History and aligned player controls.
- Playlist Play/Shuffle actions and a fix for transient black visualizer frames.
- Occurrence-aware queues: duplicate-safe manual Up next, drag/reorder/remove/jump,
  source continuation, reversible shuffle and Repeat Off/Context/Track.
- Account-scoped queue/position restoration without autoplay or a routine success notice.
- Opt-in local listening history with a recording switch, bounded retention, visible
  persistence failures and confirmed clearing. Turning recording off retains entries.
- Explicit Linux Secret Service migration with verified copy-on-write credentials,
  recovery journals and no silent plaintext fallback. GNOME Keyring's normalized
  MIME replies are supported without weakening byte/digest or session validation.
- Guarded queue-to-playlist export with confirmation, batching, revision checks and
  ordered read-back; uncertain writes stop rather than silently retrying or deleting.

## Validation and limits

140 normal tests plus isolated single-instance and Secret Service contracts passed
locally, along with strict Clippy/fmt, release-mode checking and native graphical
smoke/size checks. The user confirmed successful GNOME Keyring migration after the
compatibility fix. CI rebuilds, tests, smoke-checks and checksums this release.

- Favorite membership is learned from loaded Library pages and confirmed writes;
  startup prefetch/persistent membership caching is not implemented yet.
- Shuffle initially chooses among loaded source occurrences; later pages join as
  they load. Manual Up next stays ordered.
- Real queue-export interoperability, cancellation and multi-batch mutation tests
  remain separately opt-in. Synthetic contracts do not prove every TIDAL grant or
  revision behavior. A partial export may need manual inspection.
- P3 library power tools, lyrics/Now Playing, mini player, audio enhancements and
  Google Cast are future phases. No TIDAL Connect support is claimed.

## Install and compatibility

Download `tidal-forces-linux-x86_64` and verify it against `SHA256SUMS`. Standalone
users may make the binary executable and use `--install`; **Home Manager-managed
users must update their verified release pin instead**, not overwrite the managed
installation. See README for runtime requirements and third-party notices.

Credentials stay in the existing storage mode unless migration is explicitly
confirmed. After migrating, **do not use older player versions with that profile**:
they cannot read the new keyring metadata. Keep one credential-changing client per
profile. Existing keyring credentials from the reviewed v0.8 preview are supported.

Requires an authorized TIDAL account/subscription. No DRM bypass is provided.
