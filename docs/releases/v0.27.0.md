# Tidal Forces v0.27.0

## Organize playlists

- Drag a track's number/grip to reorder a fully loaded owned playlist in Original
  order. Insertion markers and edge scrolling guide the drop; duplicates remain
  distinct occurrences. Existing menu and Move to position alternatives remain.
- Create root folders, rename folders, and move saved playlists to the library
  root or uniquely named root folders. Right-click and Shift+F10 expose actions.
- Reorder keeps account/revision preflight and exact read-back. Folder changes use
  bounded source/result checks but cannot be atomic against other clients because
  folder revision guards are unavailable. Uncertain writes require Refresh and
  inspection, never automatic retry. Playback queues stay unchanged.
- Nested creation, folder deletion and cover editing remain unavailable.

## Optional persistent caches

- Settings → Library & Privacy offers separate, off-by-default metadata and
  artwork caches, with explicit Clear controls. Disabling retains existing files.
- Private account-scoped metadata holds up to 8 views, 10,000 rows and 8 MiB,
  including search queries. Restored snapshots are clearly marked, omit playlist
  write authority and pagination, and require Refresh before editing/loading more.
- Artwork caching accepts canonical unsigned TIDAL image URLs, validates image
  sizes/formats, and is bounded to 128 files / 64 MiB with 32 in-memory entries.
  Artwork is shared across device accounts; metadata is not. Owned crash leftovers
  count toward quotas, and pending clears are completed during graceful exit.
- No audio, credentials or signed playback URLs are stored in these caches.

## Long-pause playback fix

- Resuming after a pause of at least one minute acquires a fresh authorized stream
  and prepares the same track position before playback. Short pauses reuse the
  existing stream. This conservative policy does not assume a service URL lifetime.
- An early stream ending no longer restarts the track on retry: Play retries from
  the stopped position. Failed loads remain paused; no automatic retry loop or
  unexpected queue advancement is introduced.

## Verification

- 314 normal tests, formatting and strict Clippy passed locally. Native responsive
  review covered folder forms, cache controls and saved-snapshot presentation.
- Separately authorized live tests used only new temporary folders and an empty
  playlist, verifying supported root operations and cleanup. They do not establish
  general folder-deletion semantics or live playlist drag/drop interoperability.
- The operator reviewed the bundle and confirmed the long-pause fix in playback.
  Automated pause tests are synthetic; no agent-run audible/device tests were used.
- Installation retains the native Rust/egui single-executable architecture and
  uses the verified GitHub release artifact through Home Manager.
