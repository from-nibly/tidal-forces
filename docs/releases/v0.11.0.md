# Tidal Forces v0.11.0

## Filter and sort loaded songs

- Filter by song title, artist or album.
- Sort by title, artist, album, duration or original order, with a reverse option.
- Play shown and Shuffle shown follow the visible order. Row playback does too.
- Reset view restores normal collection playback and pagination.

These controls cover **loaded songs only**. The interface makes that scope explicit;
playback does not quietly append unfiltered pages. Load more songs to expand the
view. Changing the view leaves the current queue and playback alone.

## Keep selections predictable

Selection ranges and select-all cover shown rows. Copy and bulk queue actions use
view order, while duplicate occurrences remain distinct. Playlist removal keeps
its original occurrence position and revision checks. Manual Up next is preserved.

The filter keeps normal text-edit keyboard and clipboard behavior. Displayed rows
remain virtualized, and filtering/sorting uses a cached projection rather than
reordering the underlying source.

## Validation

167 normal tests, strict Clippy/formatting, isolated single-instance and Secret
Service contracts, release-mode checks and native smoke tests pass. Tests include
stable sorting, duplicate identity, view-order playback/copy, source continuation,
manual queue preservation, text focus and raw playlist removal positions.

Approved after native review. Complete-collection fetching, library caches and the
remaining P3 tools are separate future work. Home Manager installation of this
version is deferred during the user's configuration migration.
