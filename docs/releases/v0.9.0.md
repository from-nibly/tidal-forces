# Tidal Forces v0.9.0

The first P3 library-tools slice: select tracks, copy links and queue ordered batches.

## Highlights

- Independent selection for duplicate track occurrences, with checkboxes and a mixed
  select-all indicator. Ctrl/Shift-click selects individual tracks or ranges.
- Shift+Up/Down/Home/End selects keyboard ranges, including off-screen virtual rows.
  Ctrl+A selects loaded tracks only; it does not fetch or claim unloaded pages.
- Copy links / Ctrl+C copies public TIDAL track URLs in source order, with duplicates
  preserved. Text fields retain their own clipboard and selection shortcuts.
- Selection actions → Play next / Add to Up next preserves batch order and duplicate
  occurrences. Invalid IDs, queue capacity or exhausted occurrence IDs reject the
  whole batch without partially changing the queue.
- Selection survives appended pages and clears on replacement, refresh, navigation
  or account changes. Existing playlist raw indices, ETags and removal confirmation
  are preserved.

## Validation and limits

148 normal tests plus isolated single-instance and Secret Service contracts passed
locally, alongside strict Clippy/fmt, release-mode checking and native graphical
smoke/layout checks. Tests cover 10,000-row keyboard navigation, duplicate copying,
text-edit shortcut ownership, raw-index removal and atomic queue failure. CI
rebuilds, tests, smoke-checks and checksums the release.

**Ctrl+V into a playlist is not implemented in this version.** Playlist paste,
filter/sort, caches/favorite membership loading, safe bulk account edits, playlist
metadata/reordering, pins and capability-gated folder/cover work remain later P3
slices. No live account-mutation tests were performed for this release.

## Install

Verify `tidal-forces-linux-x86_64` against `SHA256SUMS`. Home Manager installations
must update the verified release pin and switch configuration, not run `--install`
over the managed executable. Standalone users may use `--install` after verification.
See README for dependencies, authorization limits and third-party notices.

Existing v0.8 keyring profiles remain supported. Do not use pre-keyring player
versions with a migrated profile. Requires an authorized TIDAL account/subscription;
no DRM bypass is provided.
