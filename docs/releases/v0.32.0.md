# v0.32.0 — P5 lyrics and daily-use surfaces

Native review approved, including the native-output silence fix.

## Implemented

- Dedicated command-line controls reuse the running player's bounded single-instance
  inbox and the same playback actions as MPRIS. Commands require an already-running
  compatible player; acknowledgement means queued, not playback authorization.
- Seek and confirmed playback positions retain subsecond precision through decoder
  preparation and cached seeks. UI extrapolation is bounded, stops while paused or
  buffering, and does not count as listening time. Persistent resume remains compatible
  with the existing whole-second state format.

- Full-window Now Playing opens through artwork, overflow or L, retaining the
  underlying browse/selection/panel state. TIDAL-only lyrics support guarded,
  cancellable reads, timed/plain/missing/error states, subsecond seek and follow.
  RTL or missing-glyph documents have an explicit display limitation rather than
  incorrect rendering. See [lyrics contracts](../lyrics.md).

- Branded native mini player shares transport, seek, volume, queue and source-quality
  state. Closing it leaves playback unchanged. Always-on-top requests are gated by
  native backend support.
- Opt-in Linux tray controls use bounded shared actions. Close-to-tray is supported
  only with a registered X11 host; host loss restores app-hidden windows. Native
  Wayland retains Close-as-exit because hiding/restoration is unsupported. Quit
  preserves credential guards. See [daily-use contracts](../daily-use.md).

- Optional bounded continuation uses current-track recommendations: at most three
  lookups / 150 accepted tracks per source/session or explicit re-enable. It preserves
  manual/source order, deduplicates, guards account/queue/occurrence/generation and
  never restarts stopped playback. Radio can be browsed without playing, refreshed
  without changing the queue and saved through the existing explicit export draft.
  See [recommendation contracts](../recommendations.md).

- Review feedback removes lyric hover tooltips and delegates native output routing
  to PulseAudio/PipeWire. No sink pinning, device/port fingerprint checks or
  route-change stops remain. The native picker moves only this app's stream, never
  the system default. New/legacy preferences use OS defaults; actual stream failures
  retain explicit recovery. OS fallback may include speakers after headphone removal.

- Native-output silence feedback: replaced the aggressive total-latency request with
  a 100 ms per-stream buffer and automatic server prebuffering, without requesting
  device-latency changes. A private null-sink monitor now checks actual nonzero PCM
  delivery and recovery from a writer stall, not merely advancing playback position.

## Verification and limits

Pre-feedback verification passed: 424 normal tests (8 opt-in tests excluded), strict
application Clippy on Rust 1.95 and 1.99, formatting and the optimized build.
Individually isolated single-instance, Secret Service, null-ALSA, native null-Pulse
and tray contracts passed. Synthetic native layouts, actual mini-window lifecycle,
CLI routing, eager linkage and release UI smoke passed. Upstream vendored Pulse
code emits deprecation warnings on Rust 1.99; application linting remains clean.

Post-feedback routing verification also passed: 424 normal tests (9 opt-in tests
excluded), dual-toolchain checks, strict application lint, optimized build, private
PulseAudio/PipeWire stream moves and repeated song changes, compatibility recovery,
three native output-settings layouts and release UI/mini-window lifecycle smoke.
The final native-buffer regression also measures delivered nonzero samples through
a private null-output monitor, including recovery after a deliberate writer stall.
The operator confirmed audio and the remaining P5 features in the native preview
and approved publication and installation.

Additional real-account mutations, credential migration, audible/device testing
and review-preview replacements still require separate authorization. No external
lyrics service is used.
