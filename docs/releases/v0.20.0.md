# v0.20.0 — Guarded playlist reordering

- Track menus offer **Move to playlist top / bottom**. Selecting an action moves immediately, without an extra confirmation; progress and error recovery remain visible.
- This initial slice supports fully loaded, owned playlists of 2–100 available tracks, in Original order without filtering/reverse, videos or unavailable entries. Larger playlists and middle-position/drag moves remain future work.
- Freeze account, playlist revision, complete ordered IDs and raw source position, preserving duplicate occurrences. Recheck the full source before a conditional write; require a new write revision and exact resulting order before reporting success.
- Block stale views and duplicate dispatch. Uncertain writes or verification failures require Refresh/inspection, never blind retry or rollback. The existing playback queue stays unchanged.

Verified with 241 normal tests, strict checks, native responsive fixtures and synthetic HTTP/UI contracts, including a single-click dispatch regression. Live mutation interoperability remains untested; no agent-run real account mutations or audible/device tests were performed.
