# Tidal Forces v0.16.0

## Compact track controls

- Tracks/count and full/manual loading controls now share the Play/Shuffle action row, wrapping on narrow windows instead of occupying separate sections.
- Saved tracks gain a Shuffle action using the existing guarded collection/view playback behavior.
- A hamburger menu immediately beside the sort selector contains Copy links, Selection actions, Clear, Reverse and Reset view, with the current selection count.
- The separate selection strip is removed. Keyboard selection, duplicate occurrence identity, clipboard order and view-only playback remain unchanged.
- Loading progress stays compact, with Stop loading available and detailed progress on hover.
