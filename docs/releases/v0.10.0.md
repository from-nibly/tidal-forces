# Tidal Forces v0.10.0

## Paste songs into playlists

- Copy songs, open one of your playlists, and press Ctrl+V or choose Paste tracks.
- Review a short confirmation before adding anything.
- Duplicates are skipped by default, including songs already elsewhere in the
  playlist and repeats in the copied selection. Choose Add duplicates too to keep
  every copied occurrence instead.
- Search and other text fields keep their normal paste behavior.

## Safe playlist updates

Duplicate checks read the complete destination before enabling Add songs. Changes
made elsewhere stop the operation rather than adding against stale information.
Ordered writes are checked against the destination's current account, ownership,
size and revision, then read back before continuing. Cancellation stops future
writes but cannot undo a request already in progress; uncertain results are never
automatically retried or rolled back.

Paste supports owned audio-only playlists with available revisions. Input is
limited to 4 MiB / 50,000 links, with a 50,000-song destination limit. Unavailable
rows that cannot be checked safely block confirmation. Queue export continues to
preserve repeated songs intentionally.

## Validation

161 normal tests, isolated single-instance and Secret Service contracts, strict
Clippy/formatting, release-mode checks and isolated native smoke tests pass.
Interaction tests cover confirmation, duplicate choices, text-field ownership,
large selections, cancellation and changed destinations. Automated protocol tests
use synthetic accounts; no live account mutations were used for validation.

This release was approved after native review. Filtering/sorting, library caches
and the remaining P3 tools are separate future work.
