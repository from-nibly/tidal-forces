# v0.26.0 — Move to position

- **Move to position…** moves a chosen playlist occurrence to any different one-based final position, earlier or later, in a fully loaded owned playlist in Original order.
- The destination picker sends nothing until **Move to position** is selected. Existing top/bottom/up/down actions still start immediately.
- Frozen account/revision/occurrence guards, paged source verification, one conditional write and exact paged read-back remain in place. Invalid, unchanged, oversized and stale destinations cannot dispatch; uncertain results require Refresh and inspection, never automatic retry.
- Playback queue contents stay unchanged. Drag/drop remains separate work.

## Verification

285 normal tests pass, including exhaustive position mappings with duplicate IDs, forward/backward wire contracts, actual menu/button interactions, paged read-back in both directions and rejection of incorrect forward results. Strict Clippy, formatting, release checks and responsive native fixtures/smoke checks pass.
